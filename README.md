Neon Defender: Asteroid Shield — это динамичная аркада на Java Swing с неоновым ретро-стилем, где игрок защищает рубеж, отражая энергетическое ядро в скопления астероидов.
Управление платформой осуществляется движением мыши по горизонтали.
Клавиша [ПРОБЕЛ] запускает ядро с платформы в начале раунда, [P] ставит игру на паузу, [N] начинает новую игру со сбросом прогресса, а [ESC] выполняет безопасный выход.
Цель игры — разрушить все уровни астероидов, избегая падения ядра за нижнюю границу экрана при трёх доступных жизнях.
